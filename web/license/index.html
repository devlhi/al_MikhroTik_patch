System ID atau Software ID?

CHR System ID digunakan untuk Cloud Hosted Router (mesin virtual). Salin 11 karakter System ID persis seperti yang ditampilkan; kapitalisasi tidak diubah.

RouterOS Software ID digunakan untuk ID instalasi RouterOS. Salin ID dengan format XXXX-XXXX; setiap X adalah angka 0–9 atau huruf besar A–Z, tanpa huruf O. Input tidak diubah otomatis.

Lihat menu System → License atau perintah /system license print di perangkat. Gunakan ID dari perangkat lab yang akan memakai lisensi.

Spasi di awal dan akhir dibuang. Spasi di dalam ID tidak diubah. Mengganti ID atau jenisnya menghapus hasil sebelumnya.
